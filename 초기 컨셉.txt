1. 프리미엄 구독 (★★★★★) - 가장 추천

기본 기능은 무료, 고급 기능은 월 구독.

예시

무료

SNS 링크 5개
기본 디자인
조회수 확인

프리미엄 (월 5,000~10,000원)

무제한 링크
커스텀 도메인
방문자 통계
버튼 클릭 분석
방문자 국가 분석
광고 제거
프로필 꾸미기
예약 링크 공개

이 모델은 SaaS라서 꾸준한 수익이 생깁니다.

1. 추천 기술 구성
영역	추천 기술	역할
웹 프레임워크	Next.js + TypeScript	화면, SEO, 서버 API
UI	Tailwind CSS + shadcn/ui	빠른 디자인 개발
배포	Vercel	웹 서버와 CDN
데이터베이스	Supabase PostgreSQL	회원, 프로필, 링크, 통계
로그인	Supabase Auth	이메일·Google·소셜 로그인
이미지 저장	Supabase Storage	프로필·배경 이미지
결제	토스페이먼츠	국내 구독·결제
이메일	Resend 등	가입, 인증, 알림 메일
오류 추적	Sentry	서버·브라우저 오류 확인
분석	자체 클릭 통계 + GA	방문자와 전환 분석
